# LeviosAI 🪄
> Google DeepMind Gemini 3 Seoul Hackathon Project

[Korean]
LeviosAI는 해리포터에서 윙가르디움 레비오사와 AI를 합친 명사로, AI Model을 LLM, Computer Vision, ASR(음성인식) 분야에 맞는 Hardware를 추천해 주고,
해당 분야 및 모델에 맞게 경량화를 진행하여 Edge Device에 바로 적용할 수 있도록 만든, End to End Platform 입니다.

현재 배포된 버전은 알파 테스트를 진행한 모델로서, Google Gemini-3 Hackathon에 출품한 작품입니다.
감사합니다.

[English]
LeviosAI is a compound noun combining the "Wingardium Leviosa" spell from Harry Potter with "AI." It is an end-to-end platform designed to recommend optimal hardware for AI models across various fields—including LLMs, Computer Vision, and Automatic Speech Recognition (ASR)—while performing specialized model lightweighting to enable immediate deployment on edge devices.
